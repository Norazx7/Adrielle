# GLPI Triagem Auto

Extensão Chrome **externa** (não é plugin do GLPI) para quem não tem permissão de criar modelo de tarefa.

Preenche a tarefa do chamado assim:

- Texto padrão de triagem
- Status **Feito**
- Técnico **witorio.couto**
- Grupo **DTI - CENTRAL TI - TRIAGEM**
- Clica em **+ Adicionar** (opcional)

**Desenvolvido por Witório Bandeira**

## Como usar

1. Instale em `chrome://extensions` → Carregar sem compactação → pasta desta extensão  
2. Abra um **chamado** no GLPI  
3. Clique no botão vermelho **TRIAGEM** (canto inferior direito)  
   ou no ícone da extensão → **Preencher nesta aba**

## Observação

Não altera o servidor GLPI. Só automatiza o formulário no seu navegador.
