# GLPI Triagem Auto — Guilherme

Extensão Chrome para o usuário **guilherme.apinheiro** (id `1070`).

Preenche a tarefa:

- Modelo **15** — Realizar triagem  
- Status **2** — Feito  
- Técnico **1070** — guilherme.apinheiro  
- Grupo **11** — DTI - CENTRAL TI - TRIAGEM  

**Desenvolvido por Witório Bandeira**

## Instalar

1. Extraia o zip  
2. `chrome://extensions` → Modo do desenvolvedor  
3. **Carregar sem compactação** → esta pasta  
4. No chamado, clique no botão vermelho **TRIAGEM**
